PURPOSE & OVERVIEW:
This test file validates the core database engine that underpins the entire 
Agentic Slice Kit architecture. In this kit, "the context window is a cache, 
the database is the truth." It verifies:
  1. Durable Run State: A run remembers its exact state across executions.
  2. Append-Only Invariant: Past versions/history can NEVER be edited or deleted 
     (enforced by SQLite triggers, not just software convention).
  3. Versioning & History: Latest version is easy to read, but full historical 
     diffs are preserved.
  4. Counter Persistence: Retries and token counts live in SQL tables so they 
     survive process restarts/crashes.
  5. Question Queue: Write-once human-in-the-loop question handling.
