PURPOSE & OVERVIEW:
This test file validates human-in-the-loop interaction as a first-class STATE 
rather than an exception or inline blocking call. When an agent asks a human a question:
  1. The run transitions to state AWAITING_EXPERT and the process can safely terminate.
  2. When an answer is provided, the run wakes up and transitions back to its resume state.
  3. Answers are write-once (second answers are ignored to prevent double execution).
  4. If an expert does not answer before the deadline, sweep() automatically times 
     out the question and resumes the run cleanly with an unanswered record.
